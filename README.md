# simulador-carga-baterias
## Descrição do Problema
Simula o tempo de vida útil de uma bateria de laptop considerando o nível de brilho da tela e o uso da GPU.
## Requisitos
* Receber capacidade da bateria em mAh
* Ajustar consumo base pelo brilho (0-100)
* Aplicar penalidade de consumo se GPU estiver ativa
* Calcular horas estimadas de autonomia
## Exemplo de Uso
Entrada: bateria 5000mAh, brilho 80, GPU ativa
Saída: Autonomia estimada: 2.1 horas
